# 2. 拆圖層（L2）

回到 [主流程](README.md)。

## 做什麼、為什麼

拆層模型 See-through 把一張立繪拆成約 25 層（前髮、後髮、臉、左右眼白、虹膜、睫毛、眉毛、嘴、鼻、耳、脖子、上衣、手套、下著、襪子、鞋子、帽子、手持物品、其他），被擋住的地方會猜著補，每層附深度。後面每個物件都從這裡來。

## 輸入、輸出

- 輸入：`full.png`、`fig_joints.json`。
- 輸出：
  - `st/part_<名稱>.png`：每一層。
  - `st/parts.json`：圖層的前後順序；第 3 步之後還有轉軸。
  - `st/st_*.png`：拆層模型的原始輸出和深度圖。
  - `st/_layers.jpg`：每一層單獨的總表。
  - `st/_stack_vs_plate.jpg`：疊回去跟原圖並排。

## 指令

```
python Tools/art/see_through.py <角色> <造型> --seed=42   要 ComfyUI，約 8 分鐘
python Tools/art/layer_sheet.py <工作資料夾>/st           逐層總表
```

我們加的補救（都在 `see_through.py`）：先裁到人物再拆；沒拆出臉就換種子重拆；某層在看得到的地方顏色跟原圖不同就把那一塊拿掉；每層裁到人物輪廓；原圖有、各層都沒有的放進 `leftover`，再照位置分給帽子、武器、裙子。

## 看什麼

- 審查包：`st/_layers.jpg`（每一層單獨看，最重要）、`st/_stack_vs_plate.jpg`、`st/parts.json`。
- 這一步只修「整張拆壞」和「臉」，其他物件的問題記下來，留給第 4 步逐格判、物件迴圈修。

### 注意重點

**L2 拆圖層**
- 漏掉臉、兩隻眼白合成一層或只有一隻、發明不存在的帽子或翅膀（LessonsLearned 三）。
- 拆出來的臉離骨架的臉太遠：胸前的圖案被當成第二顆頭（`inx_rig.st_usable`）。
- 披肩的長髮被丟進「其他」（三）；跟同色披風疊在一起時，髮尾被分給衣服（三）。
- 手放在東西上會黏成一塊（艾莉西亞的右手和箭筒），之後會跟著手飛（三）。
- 「其他」佔人物一大半時（芙蕾雅的寬帽、杖、裙襬），看程式有沒有把帽子、武器、裙子分對（`refine_leftover`）。
- 被擋住的部分是模型猜的、常猜錯（額頭灰、帽帶抄進臉、帽簷殘影、後髮灰白）（三）：這裡先記下，留給物件迴圈修。
- 被擋住的地方猜錯的先記下來，用 `to_objects` 交給物件迴圈。

## 修法選單

| 修法 | 什麼時候用 |
|---|---|
| `reseed` 換種子 | 整張拆壞 |
| `make_face` 重做臉 | 臉太小、混了帽帶或頭髮（取立繪的皮膚） |
| `split_lr` 左右切開 | 兩隻眼白／虹膜合成一層 |
| `drop_part` 刪層 | 發明出來的層（翅膀、多一頂帽子） |
| `sort_hair` 整理頭髮 | 長髮被丟進雜物層 |
| `move_hair` 搬頭髮 | 髮尾被分給同色的衣服 |
| `to_objects`（通過時） | 交給物件迴圈 |

## 常見問題和現在的處理

芙蕾雅主設計（種子 42）每一輪都一樣：

| 問題 | 處理 | 狀態 |
|---|---|---|
| 臉只有約 3500 像素、上半是帽帶的黑 | `make_face` | 選單 |
| 右眉是一塊黑（帽簷） | 物件迴圈鏡像 | 選單 |
| 右耳只剩一條線 | 物件迴圈鏡像 | 選單 |
| 火球散在雜物層、下著、右手 | 第 4 步切出 `held-r`，第 4a 步整個拿掉 | 選單 |
| 帽子右邊紅色帽簷底面掉在雜物層 | 物件迴圈重畫帽子，雜物層清空 | 選單 |
| 前髮碎、夾帽簷黑線；後髮頂上有帽子輪廓 | 物件迴圈 Qwen 重畫 | 選單 |

## 已知問題

- 這些錯每次都一樣，等於每一輪都在補拆層模型的同一批錯。想法：拆層之前先處理立繪（擦掉手上的東西、補被擋住的部分），或某些部位不用拆出來的（臉用固定的臉形工具）。
- 放大、補細節後再拆，沒有一致變好（臉、眼珠好一點，耳朵、眉毛、鼻子更差）（[22e](../Design/22e_Upscale.md)）。
