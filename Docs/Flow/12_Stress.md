# 12. 極限測試（L12）

回到 [主流程](README.md)。

## 做什麼、為什麼

每個關節轉到範圍的兩端，一次轉一個，用遊戲的播放器畫出來，跟靜止時比：找背景透出來的洞（洋紅）和移走的零件還留在原處的殘影（青色）。標準動作只用到一部分角度，技能動作可能轉更多，這一步找出哪裡會破。

## 輸入、輸出

- 輸入：`<名稱>_st.inx`、`parts.json`（只讀清單裡的圖層算身體）。
- 輸出：`check/<名稱>_stress.jpg`（每個姿勢一格）、每個姿勢一行的結果；`--find-ranges` 時把每個關節的安全範圍寫進 `parts.json` 的 `ranges`。

## 指令

```
python Tools/art/rig_stress.py <角色>/<造型>                  有洞或殘影大於門檻就結束代碼 1（提示）
python Tools/art/rig_stress.py --find-ranges <角色>/<造型>    找每個關節不出問題的範圍
```

## 看什麼

- 審查包：`<名稱>_stress.jpg`；標出來的格放大看。

### 注意重點

**L12 壓力測試**
- 先排除誤報：手臂移開後露出人物外面的背景是正常的；小轉動時零件邊上的細條不算。
- 真的問題：手臂底下沒補畫（`hidden`）、關節裂縫、手指留在身體層、排在後面的武器被前面的層畫成立繪顏色（殘影）。
- 修不好的關節用 `--find-ranges` 縮小範圍，技能動作留在範圍內；但找出來的範圍全是 0（腿一轉就有殘影）時不要寫進去，那等於不能動。
- 這個測試抓不到關節的段差和凸塊（2026-10-02 手肘的例子），關節要另外放大看。

## 修法選單

| 修法 | 什麼時候用 |
|---|---|
| `to_objects` | 零件或補畫層要修 |
| `find_ranges` | 找安全範圍 |
| `rerig` | 綁定要重做 |

## 常見問題和現在的處理

| 問題 | 處理 | 狀態 |
|---|---|---|
| 手上的東西被當成身體，手一動就報大洞 | `held-` 算會動的 | 已修 |
| 資料夾裡的備份檔被算進身體 | 只讀 `parts.json` | 已修 |
| 髖轉 ±1.2 時裙子邊破洞、左膝殘影 | 標準動作沒用到這麼大 | 已知未查 |
| 腰彎 ±0.6 時長裙裂開 | 不用腰彎 | 已知未查 |
| 拿掉法杖後左手臂各關節約 270 像素的洞 | 法杖原本擋住的身體後面沒補 | 已知未修 |

## 已知問題

- 想加：兩段相接處的寬度差、凸塊（跟靜止時的輪廓比），補上抓不到段差的缺口。
