# 4. 分包檢查（L4）＋ 4a 只留人物

回到 [主流程](README.md)。

## 做什麼、為什麼

把所有圖層照固定規則分成六包，每包一張總表、每個物件單獨一格，**逐格**判斷：看得出是什麼嗎、完整嗎、乾淨嗎、符合名字嗎。這是主要關卡：有問題的物件送進物件迴圈（第 5 步）。組起來時物件互相擋住，物件本身的缺塊、碎片、白洞只有在這裡看得到。

| 包 | 內容 |
|---|---|
| 1 臉部 | 臉、眼白、虹膜、睫毛、眉毛、嘴、鼻、耳、脖子、臉上的飾品 |
| 2 頭髮與髮飾 | 前髮、後髮、側髮、髮尾、馬尾、呆毛；**戴在頭上的帽子、髮帶也算這包** |
| 3 軀幹與衣物 | 上衣（胸、腹）、下著、補畫層 `hidden`、`hidden-pelvis` |
| 4 四肢 | 上臂、前臂、手；大腿、小腿、腳掌（連鞋）各兩 |
| 5 武器 | `objects`、`objects-back` |
| 6 其他物件 | 雜物層 `leftover`、手上拿的東西 `held-l/r`、身上的小東西 |

名字和包的對照在 `Tools/art/part_names.py`。

## 輸入、輸出

- 輸入：`st/part_*.png`、`parts.json`。
- 輸出：`st/groups/parts_1.jpg`～`parts_6.jpg`（部件檢查）、`assemble_1.jpg`～`assemble_6.jpg`（一包一包疊起來，第 6 步用）、`groups.json`（哪層在哪包、警告）。

## 指令

```
python Tools/art/split_groups.py <角色> <造型>
```

紅字警告：缺必有的、左右只有一隻、左右大小或顏色差太多、幾乎是空的、超過 5% 跑到人物外面。只是提醒。

## 看什麼

- 審查包：`parts_1.jpg`～`parts_6.jpg`，每一格都要有一筆結論。

### 注意重點

**L4 部件檢查**
- 每一格都要看，先問「看得出來這是什麼嗎」（原則 0），再看完整、乾淨、符合名字（原則 1）。艾莉西亞的右上臂只是一塊上衣的白布、右手裡混著前臂和箭筒，就是看不出是什麼的例子。常見的髒：帽子、披風黏著頭髮碎片；髮尾裡有白洞；側髮切成碎塊；「其他」只剩垃圾。
- 被擋住的也要畫完整；左右成對的少一邊要從另一邊補（原則 6）。左右一對的大小、顏色差太多（一隻黃靴、一隻深褐）。
- 穿過人物的東西（帽子、圍巾、腰帶、繞過身體的武器）要拆成前後兩層（原則 7）。
- 會擺動的衣物（寬袖、披風、裙擺、馬尾、呆毛）要單獨切出來，才會擺。
- 零件上的小碎點會跟著零件飛（LessonsLearned 五）。
- 輪廓被切斷沒有可靠的自動判斷，只能靠看。
- 目前只做人物（使用者 2026-10-02）：武器、手上拿的東西（火球等）不送進物件迴圈；散在別的層裡的手上物件用 `carve` 切成 `held-<l|r>`，下一步整層拿掉。帽子、髮飾算人物。

## 修法選單

| 修法 | 什麼時候用 |
|---|---|
| `to_objects` | 這個物件要修（送進物件迴圈） |
| `carve` 切出新物件 | 一個東西散在別的層（火球在下著、手上），用顏色、方框、多邊形切到一層（切到已有的層會合併） |
| `split_hair` | 長髮拆成側髮、髮尾 |
| `split_front` | 穿過人物的東西拆前後兩層 |

## 只留人物（4a）

- 沒有檢查點：`object_fix.py <角色> <造型> - --drop-objects` 把武器包和 `held-*` 整層從 `parts.json` 拿掉（原檔留在 `st/_orig/`），再重新分包。
- 要做物件時，把 `plate.toml` 的 `character_only` 和第 13 步的 `skip` 拿掉。

## 常見問題和現在的處理

| 問題 | 處理 | 狀態 |
|---|---|---|
| 分包時把雜物層裡頭部那塊叫成 `leftover-head`（不是真的圖層） | 流程程式不開沒有圖層檔的物件（2026-10-03 改） | 已修 |
| 被拿掉的物件（武器、手上的東西）已經送進物件迴圈 | 流程程式跳過圖層已不在的物件 | 已修 |
| 每一輪大半的判斷都一樣（臉、眉、耳、帽子、火球） | 照上一輪的結論交 | 重複勞動 |

## 已知問題

- 第 4 步的結論大半每一輪都一樣，還是要逐格交。想法：同一張立繪、同一個種子重跑時，帶入上一輪的判斷當預設，只看有變的格。

## 每包的圖層

「必有」＝每張立繪都該有，沒有就是拆壞了（分包時會警告）；「可能」＝看造型和姿勢，沒有是正常的。括號裡是檔案名稱（`st/part_<名稱>.png`）。

**被遮住的也要畫完整**：每個部件都要是完整的，被頭髮、手、衣服或角度擋住的部分也要補畫出來，否則轉頭、甩頭、揮手這些大動作時會露出破綻。左右成對的部件（眼白、虹膜、睫毛、眉毛、耳朵、手臂）兩隻都要有：側臉或被擋住只拆出一隻時，另一隻要補畫（分包時會警告「只有一隻」）。原圖上完全沒有的，用 AI 照另一側的樣子補出來：以臉（或身體）的中線把看得到的那隻鏡像過去當底稿，再用 AI 局部重繪修成這一側的角度和光影，一樣要跟原圖畫風一致。整個部件都沒拆出來的（例如眉毛整個被帽簷擋住），也用 AI 照角色的樣子畫在被擋住的位置。

### 1 臉部（跟著頭轉）

| 圖層 | | 說明 |
|---|---|---|
| 臉 `face` | 必有 | 臉的皮膚 |
| 左右眼白 `eyewhite-l/r` | 必有 | 兩隻都要有；側臉或被瀏海擋住時，看不到的那隻也要補畫 |
| 虹膜 `irides-l/r` | 必有 | 兩隻都要有；側臉時拆層模型會把兩眼合成一層 `irides`，要分開並補畫看不到的那隻 |
| 睫毛 `eyelash-l/r` | 必有 | 兩隻都要有；眨眼時往下蓋 |
| 眉毛 `eyebrow-l/r` | 必有 | 兩隻都要有；被瀏海或帽簷擋住的部分也要補畫完整 |
| 嘴 `mouth` | 必有 | |
| 脖子 `neck` | 必有 | |
| 鼻 `nose` | 可能 | 日系畫風的鼻子常只有一點 |
| 耳朵 `ears-l/r` | 可能 | 造型有露耳時兩隻都要有；被頭髮蓋住的部分也要補畫 |
| 臉上的飾品 | 可能 | 護目鏡、眼鏡、耳環（從「其他」切出脖子以上的部分）。戴在頭髮上的（帽子、髮帶、髮夾）算第 2 包 |
| 領口 | 看一下 | 在上衣裡，這包一起看，綁定時留在身體上 |

### 2 頭髮與髮飾（各自有擺動的物理）

頭髮本身加上戴在頭髮上的東西算同一類；**戴在頭上的帽子也算髮飾**（使用者 2026-10-02）。它們疊在一起、跟著頭髮一起擺，部件動作測試一起看（`pack=hair`）。

| 圖層 | | 說明 |
|---|---|---|
| 瀏海 | 必有 | 額頭前面那片 |
| 後髮 | 必有 | 頭後面的主體 |
| 左右側髮 | 可能 | 臉兩旁垂下的髮束（鬢角、長側髮） |
| 馬尾／雙馬尾／辮子 | 可能 | 綁起來、離開頭部的髮束 |
| 長髮髮尾 | 可能 | 過肩的長髮下半段（擺動比上半段大） |
| 呆毛 | 可能 | 頭頂翹起的一撮 |
| 帽子 `headwear` | 可能 | 戴在頭上的帽子 |
| 髮帶、髮夾 `ribbon-…` | 可能 | |

拆層模型只分前髮 `front_hair`、後髮 `back_hair` 兩層，上表的細分要在拆完後再切（瀏海和側髮從前髮切，馬尾、髮尾、呆毛從後髮切）。

- **長髮要拆成多個髮片**（使用者 2026-10-02）：`object_fix <角色> <服裝> front_hair --split-hair --hair-ends N`。前髮在眼睛以下、臉兩旁的切成左右側髮；後髮肩膀以下的切成 N 片髮尾，片與片的邊界沿著頭髮自己的線稿走（從每片中間長出去、碰到深色線停下），不是直線切；每片往上、往旁邊多帶一點重疊，擺動時切口不會裂開。每片綁定時有自己的擺。
- **後髮是從正面看進去的內側**（使用者 2026-10-02）：正面立繪的後髮，是頭和身體後面露出來的那片頭髮，看到的是它朝前的內側（比較暗、有陰影），不是從背後看的後腦勺（有頭頂、髮旋）。AI 重畫時不要叫它「畫出長長的後髮」，要叫它「把人擦掉，人原本的位置畫上後面那片頭髮的暗色內側」。

### 3 軀幹與衣物（身體跟穿在身上的衣服一起切；胸會呼吸、有乳搖，腰可以彎）

| 圖層 | | 說明 |
|---|---|---|
| 胸 `chest` | 必有 | 胸口到胸下緣，連著上衣這一段；呼吸時起伏，乳搖的物理掛在這裡 |
| 腹 `abdomen` | 必有 | 胸下緣到腰，連著上衣或腰封這一段；腰彎的時候跟著彎 |
| 小腹 `belly` | 可能 | 腰到下著上緣，露出小腹或衣服在這裡分段的造型才有 |
| 下著 `bottomwear` | 可能 | 裙子、短褲、褲裙，掛在骨盆上；連身裙時沒有 |
| 身體底下補畫 `hidden`、裙子往上延伸 `hidden-pelvis` | 可能 | 手臂、腿、武器移開後，或上身彎下時露出來的身體和衣服（切零件時補畫） |

拆層的上衣 `topwear` 是原料（含領口、披風、外套；連身裙也在這層），切成胸、腹、小腹後就不直接用了。披風、外套下擺這種會自己擺動的，之後可以再切出來加物理。

**乳搖**：胸 `chest` 的網格下半部掛一個彈簧擺的物理，身體上下移動（走、跑、跳、受擊）時跟著晃，停下後回穩；幅度保持輕微自然，跟頭髮物理同一套做法。胸是完整的一塊，不另外挖洞，所以晃的時候不會露出縫。角色一律是成年人，服裝照原圖，不做裸露。

### 4 四肢（連鞋子）

| 圖層 | | 說明 |
|---|---|---|
| 左右上臂 `upperarm-l/r`、前臂 `forearm-l/r`、手 `hand-l/r` | 必有 | 從拆層的手臂 `handwear-l/r`（連手套）切出，肩、肘、腕可以轉；兩隻手臂都要有，被身體或武器擋住的部分也要補畫 |
| 左右大腿 `thigh-l/r`、小腿 `shin-l/r` | 必有 | 從拆層的腿 `legwear`（連襪子，兩條腿同一層）切開左右再切段，髖、膝可以轉；被長裙或另一條腿擋住的部分也要補畫 |
| 左右腳掌 `foot-l/r`（腳踝以下，連鞋子） | 必有 | 光腳或穿鞋都要：從腿 `legwear` 和鞋子 `footwear` 切出腳踝以下，鞋子跟著腳掌走；腳踝可以轉（踮腳、跳躍落地、走路） |

拆層的 `handwear-l/r`、`legwear`、`footwear` 是原料，切好零件後就不直接用了。

### 5 武器

| 圖層 | | 說明 |
|---|---|---|
| 手持物品 `objects` | 必有（英雄） | 四位英雄都拿武器；其他角色是「可能」 |
| 被擋住那段 `objects-back` | 可能 | 武器被身體或衣服擋住的部分（切零件時補畫，跟著武器轉） |

| 圖層 | | 說明 |
|---|---|---|
