# 11. 標準動作（L11）

回到 [主流程](README.md)。

（舊編號 L9、第 6 步。）

## 做什麼、為什麼

一組固定的十個動作，每位角色、每張立繪都一樣，好比較；武器和物件藏起來（`bare`），只看人物。先關掉擺動跑一次（看關節），再打開擺動跑一次（看頭髮、裙子），出問題才分得出是關節還是擺動的錯。

| 動作 | 看什麼 |
|---|---|
| 走路 | 上下起伏、左右晃、雙手前後擺、頭輕輕點 |
| 跳躍 | 蹲、跳起、落地壓扁，頭髮和衣服的甩動 |
| 跑步 | 快步起伏、身體前傾、手臂擺動、轉頭 |
| 揮手 | 舉起右手揮動、歪頭、微笑開口 |
| 頭部動作 | 左右轉頭、點頭、歪頭 |
| 眨眼與表情 | 眨眼、眼睛左右看、挑眉、說話 |
| 呼吸待機 | 呼吸、眨眼、慢慢看 |
| 甩頭 | 快速轉頭兩秒再停，看頭髮甩動和回穩 |
| 受擊 | 往後一晃、頭甩開、閉眼，再回穩 |
| 轉身看 | 眼睛先轉、頭再跟上，再轉回來 |

## 輸入、輸出

- 輸入：`<名稱>_st.inx`。
- 輸出：`_motions_nophys/`、`_motions_phys/`（每個動作一組畫面、`frames.json`、`sheet_<動作>.jpg`、`report.json` 列出缺的參數），`_score/L11.json`。

## 看什麼

- 審查包：兩組的 `sheet_<動作>.jpg`、`report.json`、`_score_L11.json`。
- 每個動作取幾格裁出人物看；**關節要用原圖解析度畫出那個姿勢放大看**（`rig_render.tscn` 帶 `frames.json` 的參數），動作截圖裡人物太小。
- 給使用者看：每個動作做成會動的圖（GIF），和 10 欄 × 6 列的逐格總表。

### 注意重點

**L11 人物的標準動作**
- 先看關掉擺動（`_motions_nophys`），再看打開擺動（`_motions_phys`）。
- 程式只能確認參數齊不齊；破綻要看畫面：東西跟著手飛（箭筒）、手腕有縫、碎片在飛（LessonsLearned 十一）。
- 站得窄的角色腿會交叉；長裙裡的腿不能踢出裙外（八）。
- 揮手時手臂要往外舉，不是往胸前收（參數方向左右一致，八）。
- 裙子、頭髮要慢半拍甩、會停下來；擺不動表示擺掛錯節點；擺兩倍快表示一格更新了兩次（八、九）。
- 手臂舉起來後露出的 `hidden` 有沒有灰色糊塊；胸的切口有沒有縫。
- 細微的動作（胸部彈動、領口）縮圖看不出來，要實際大小、實際速度看（十一）。
- 關節（手肘、膝蓋）在動作截圖裡只有幾個像素，說「修好了」之前要用原圖解析度放大確認（2026-10-02，說錯兩次）。
