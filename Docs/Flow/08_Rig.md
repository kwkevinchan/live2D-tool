# 8. 綁定（沒有檢查點）

回到 [主流程](README.md)。

## 做什麼、為什麼

照圖層名字和 `pivots` 自動做出 Inochi2D 模型：每個零件掛在哪個節點、轉軸在哪、哪些有擺動（物理）、哪些跟著關節變形。綁得好不好由後面四步（9～12）的動作來看，這一步本身不審查。

## 輸入、輸出

- 輸入：`parts.json` 列出的圖層（**只讀清單裡的**，資料夾裡別的 `part_*.png` 不算，2026-10-02）、`pivots`、`fig_joints.json`、嘴型、閉眼差分。
- 輸出：`<角色>_<造型>_st.inx`（Inochi2D 0.8，可以再用 Inochi Creator 手調）。主設計的名稱是 `<角色>_default`。

## 指令

```
python Tools/art/inx_rig.py <角色> <造型>      不用 ComfyUI，幾秒
```

## 綁定規則（摘要）

| 東西 | 掛在 | 擺動 | 連動 |
|---|---|---|---|
| 頭髮（瀏海、側髮、後髮、髮尾、馬尾、呆毛） | 頭 | 有；髮尾比髮根大；頭髮類擺動放大 3 倍（後髮 1.5 倍） | — |
| 帽子、髮帶、耳環 | 頭 | 帽簷、帽尖、垂飾輕微 | — |
| 上衣、胸、披風 | 腰 | 胸輕微彈、披風重 | 呼吸、領口跟轉頭、袖子跟上臂 |
| 手臂三段 | 肩→肘→腕 | — | 參數 +1 兩邊都是往外、往上 |
| 裙子 | 骨盆 | 左右兩半各擺 | 跟大腿（長裙 80%、短褲 100%）；長裙裡髖膝範圍縮小 |
| 腿三段 | 髖→膝→踝 | — | — |
| 武器 | 握點 | 流蘇 | 長武器握點反向轉一部分保持直立 |
| 手上的東西 `held-*` | 手腕 | — | 單獨測人物時藏起來 |

完整的表、常數（`SWING`、`HAIR_GAIN`、`SKIRT_FOLLOW`…）：[../Code/05_Rig.md](../Code/05_Rig.md)、[../Design/22b_Live2D_Flow.md](../Design/22b_Live2D_Flow.md) 的「骨架與連動」。
