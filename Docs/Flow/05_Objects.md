# 5. 物件迴圈（L5a 輪廓 → L5b 候選 → L5c 擺放）

回到 [主流程](README.md)。

## 做什麼、為什麼

第 3、4 步點名的每個物件各自走一個小迴圈，修到「看得出是什麼、完整、乾淨、符合名字」。一個物件一件小工作（`objects/<名字>`），照固定順序**由後往前**修（身體、腿先，手臂、頭髮、帽子後）：前面的東西擋著後面的，後面的先補好，前面的才有東西可以蓋。

**先輪廓、後顏色**（使用者 2026-10-01）：形狀由輪廓線決定，輪廓外的就是雜點，輪廓裡沒顏色的就是要補的，判斷才明確。

```
5a 輪廓：抽出這個物件的輪廓，選怎麼修
   └→ 5b 候選：修法產生 3～4 張候選，挑一張、選怎麼擺
        └→ 5c 擺放：放上去、重新分包，看位置和遮擋；還不對就再選修法
             └→ 通過（凍結）→ 下一個物件；全部通過 → 第 6 步
```

不需要挑候選的修法（清碎點、去毛邊、平塗、收關節）從 5a 直接跳到 5c。

## 輸入、輸出

- 輸入：`st/part_<物件>.png`、`parts.json`、立繪、`fig_joints.json`、`pivots`。
- 輸出：
  - `st/outline/<物件>.jpg`：輪廓檢查圖。
  - `st/fix/<物件>_<種子>.png`、`st/fix/<物件>.jpg`：修補的候選。
  - `st/gen/<物件>_qf<種子>.png`、`st/gen/<物件>_qf.jpg`：Qwen 重畫的候選。
  - 換上去的 `st/part_<物件>.png`：第一次修改前的原檔留在 `st/_orig/`。
  - `parts.json` 裡 AI 畫的物件會標 `drawn`。

## 指令

```
python Tools/art/outline.py <角色> <造型> <物件>            5a：輪廓檢查圖（綠＝畫出來的邊、紅＝切開的邊、黃＝丟掉、藍＝補的線、洋紅＝要上色）
python Tools/art/object_fix.py <角色> <造型> <物件> ...      修補類（鏡像、補洞、照輪廓上色、平塗、清碎點、去毛邊、收關節）
python Tools/art/object_edit.py <角色> <造型> <物件> --engine qwen --fast --instr "..."   AI 重畫（Qwen-Image-Edit-2511）
python Tools/art/object_place.py <角色> <造型> <候選> --as <物件> [--box x0,y0,x1,y1 | --fit]   放上去
python Tools/art/outline.py <角色> <造型> <物件> --check     5c：一整塊、輪廓外沒東西、沒上色的少於 2%（提示）
```

## 看什麼

### 注意重點

**L5a 輪廓**
- 擋在前面的東西的邊線，不是這個零件的邊：曾經把裙子前片的邊當成小腿的邊接起來，整塊被塗黑（LessonsLearned 五）。接線前先跟另一邊比。
- 被線隔開但還連著的區塊（黏在手臂上的披風），程式分不出來，要看編號決定 `--drop`。
- 成對的四肢有三成以上落在另一邊外面，表示混進了別的東西的輪廓（`outline.py`）。
- 邊緣的頭髮殘邊不要留給 AI 上色（會擴散成一圈紅邊），直接 `--erase-rgb` 刪掉（五）。
- 自動補線有時往外拉出一大塊要上色的範圍（小腿、袖口外）：那是錯的，不要照輪廓上色，改用去毛邊或別的修法。
- 通過時從 pass_menu 挑出候選的做法（被擋住的用 AI 重畫，四肢先試鏡像）。

**L5b 候選**
- pick 寫挑中的那一張（`st/gen/<圖層>_qf<種子>.png` 或 `st/fix/<圖層>_<種子>.png`）；都不好就 redo。
- 從灰底重畫，AI 常照著背景留灰；檢查補的地方有沒有灰塊（五）。
- 「取最近的顏色」會拉出條紋，大片單色要用 `--palette`（五）。
- 鏡像的零件只能沿骨頭拉長，看有沒有整隻變粗（五）。鏡像的翻轉 0（不經 AI）常常最乾淨。
- 鏡像的零件沒有關節重疊，一彎就裂：鏡像後做關節收尾（`cap`）（五）。
- AI 畫的長東西（長髮、披風）末端是截平的直線，表示參考框太小；`--pad` 加大或 `--mask` 把相關的層算進來（六）。
- 物件只要正確、風格接近就好，不用跟原圖一樣（使用者 2026-10-02）。AI 畫的物件形狀和原圖不同而在組裝時擋到別的東西（帽簷蓋住眼睛），用放置的位置和大小解決（`--box`），不要為了像原圖改用原圖去切（原則 2）。
- AI 重畫用混合版：Qwen 快速 4 步每個物件 3 張先挑，三張都不行再用 40 步補 1～2 張（六、[22c](../Design/22c_Object_Generation.md)）。
- 去背（rembg）會把物件本身的白色（白手套、火球的白核心）、分開的小塊當背景挖掉；有這種的用 `--matte white`（六）。
- AI 會多畫東西（空握的手多一截黑袖口）：放上去前刪掉。
- AI 重畫擅長頭髮、披風、帽子、直的武器；不擅長四肢、彎的武器（六）：四肢的候選要看得更嚴。
- 後髮要畫成從正面看進去的內側，不是背影（指令：「把人擦掉，畫後面那片頭髮的暗色內側」）（六）。
- 畫風要跟立繪一致（同一個模型和角色微調）。

**L5c 換上之後**
- AI 畫的物件對位：細長的東西（法杖、手臂）用整體重疊對位容易歪，要看握點、關節點有沒有對上；拿碎掉的原物件當目標會被帶歪，改用看圖量出的框 `--box`（六）。
- 放回去後看它有沒有蓋住原圖看得到的東西（帽簷蓋住眼睛、頭髮從帽子冒出來、臉旁的淡色殘影）（六）。
- 前後順序：戴在頭上的帽子要排在前髮前面（改 `parts.json` 的順序）。
- 不要用 `--merge` 把立繪的像素貼回去（原則 2）。
- 用方框切出來的零件（胸）邊緣會有縫，改用 `--carve-copy`（五）。
- 整層被切空的要刪掉，不要留在順序裡。
- 四肢的關節：用原圖解析度畫手肘、手腕、膝蓋、腳踝轉到極限的姿勢，放大 3～4 倍看有沒有裂縫、凸塊、段差（五、十一）。只疊那幾段零件、照轉軸轉來看最清楚。
- 每一節四肢都要：去毛邊（`defringe`）之後，再把關節收成半圓（`cap`，即 `--round`，一個關節做一次，兩段一起改）；先去毛邊，收尾才不會把毛邊複製進去（五）。

## 修法選單

| 修法 | 停在 | 做什麼 | 什麼時候用 |
|---|---|---|---|
| `edit_fast` | 5b | Qwen 快速版（4 步）畫 3 張 | 被擋住一大塊、拆壞的頭髮、帽子、AI 擅長的東西；握東西的手改空手 |
| `edit_slow` | 5b | Qwen 40 步（約慢 10 倍） | 快速版三張都不行 |
| `mirror` | 5b | 拿另一邊翻過來（候選 0 是單純翻轉，1～3 經 AI 輕修），四肢自動做關節收尾；沒有骨頭的（耳、眉）以兩眼中間翻 | 成對的一邊拆壞了 |
| `fix_outline` | 5b | 照輪廓線稿上色 | 輪廓對、裡面缺色 |
| `fix_fill` | 5b | 補缺的範圍（`--box` 指定、`--grow grey` 重畫灰色糊塊） | 補畫層的洞、灰塊 |
| `outline_marks` | 5a | 標記：刪編號區塊、刪多邊形、刪邊上某色、手描一段線（存 `marks.json`） | 輪廓判斷錯 |
| `carve`、`split_front` | — | 再拆 | 一個物件裡其實是兩樣東西 |
| `flat` | 5c | 輪廓裡猜錯、被擋住的改成看得到的顏色（`--nearest` 取最近的） | 小缺口、被瀏海蓋住的額頭 |
| `drop_specks` | 5c | 刪小於 N 像素的分開碎點（N 比整層大＝清空） | 碎點；雜物層清空 |
| `defringe` | 5c | 只留主體（斷開細線連著的條也拿掉）、刪邊緣顏色不對的一圈和離邊的小點；陰影不動 | 四肢每一節 |
| `cap` | 5c | `--round`：這一節和相鄰一節在關節收成同一個圓心（兩段中心線的中點，也成為轉軸）、同一個半徑的半圓；側邊平順收到半徑，花紋跟著拉；腳只補不切 | 四肢每個關節（手肘、手腕、膝蓋、腳踝） |
| `place_box`、`place_fit`、`place_plain` | 5c | 放上去：照量好的框／跟原物件整體對位／AI 畫的原位 | 5b 通過時 |
| `apply` | 5c | 套用 `st/fix/` 的候選 | 修補類通過時 |
| `manual` | — | 選單外的手改，寫清楚改了什麼 | — |

## 常見問題和現在的處理

芙蕾雅主設計兩輪的做法（同一張立繪，大多會一樣）：

| 物件 | 做法 | 狀態 |
|---|---|---|
| 補畫層 `hidden` | `fix_fill` 補左大腿原位的洞；刪人物外、腰以上上衣外 | 選單＋手改 |
| 左大腿、左小腿、左腳、右腳 | `defringe` | 選單 |
| 右大腿、右小腿 | 左邊 `mirror`（挑翻轉 0）、`defringe` | 選單 |
| 膝蓋、腳踝 | `cap`（在小腿那一步，兩段一起） | 選單 |
| 左上臂、左前臂 | `defringe` | 選單 |
| 右上臂、右前臂 | 左邊 `mirror`（翻轉 0） | 選單 |
| 左手（握杖） | `edit_fast` 空握的拳頭（`--matte white`），刪多畫的黑袖口 | 選單＋手改 |
| 右手（托火球） | 刪火光像素、手心小洞補色；`defringe` | 手改＋選單 |
| 手肘、手腕 | `--round`（在手的那一步手改執行） | 手改 |
| 右耳、右眉 | `mirror`（以兩眼中間） | 選單 |
| 後髮 | `edit_fast` 內側，`place_plain` | 選單 |
| 前髮 | `edit_fast`（`--pad 0.8` 讓髮尾整段在框內），`place_box 260,120,530,500` | 選單 |
| 帽子 | `edit_fast`，`place_box 133,2,621,240`；排到前髮前面 | 選單＋手改 |
| 雜物層 | `drop_specks 100000` 清空 | 選單 |

## 已知問題

- **鏡像的手臂形狀不對**：左上臂主要是露肩的荷葉袖，鏡像到右邊再接前臂，雖然收了半圓可以動，但不像一隻真的手臂。想法：整隻右手臂用 AI 重畫（Qwen 畫四肢不行；可以試付費的 Gemini）。
- **關節收尾的順序流程不知道**：要相鄰兩節都修好才能收，現在靠 LLM 記得在第二節做；手肘、手腕這次還是手改執行。想法：做成第 5 步結束前的固定步驟（所有四肢通過後一次收所有關節）。
- 握東西的手、黏著手上東西的手，在「只留人物」時應該自動處理，現在是逐個手改。
