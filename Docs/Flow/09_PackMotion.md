# 9. 部件動作測試（L9）

回到 [主流程](README.md)。

（舊編號 L6b、第 4b 步。）

## 做什麼、為什麼

綁定之後、整體動作之前，**一包一包**動：只畫那一包加上它底下的補畫層，把它的每個參數轉到 +1、-1。整體一起動時物件互相擋住，問題容易被蓋掉（武器黏著的裙子碎片、大腿底下補畫層的洞、手臂後面的糊塊，都是在這裡才看到的）。

| 包 | 畫什麼 | 轉什麼 | 擺動 |
|---|---|---|---|
| `arms` | 上衣、補畫層、脖子、兩隻手臂 | 肩、肘、腕、移動 | 關 |
| `legs` | 裙子、骨盆補畫層、兩條腿 | 髖、膝、踝 | 關 |
| `head` | 臉（只有臉部） | 轉頭、點頭、歪頭、眨眼、張嘴 | 關 |
| `body` | 上衣、裙子、補畫層、胸、披風 | 呼吸、腰彎 | 關 |
| `hair` | 頭髮、帽子、髮飾、臉 | 轉頭、點頭、歪頭 | **開**（看的就是擺動） |
| `weapon`、`held` | 武器、手上的東西加拿著的手 | 跟著手轉 | 關（目前只做人物，不跑） |

## 輸入、輸出

- 輸入：`<名稱>_st.inx`。
- 輸出：`_packs/pack_<包>/anim_*.png`、`frames.json`（每一格的參數值），`_packs/sheet_pack_<包>.jpg`（每包一張最大動作總表）。

## 指令

```
<Godot> --audio-driver Dummy --path . res://Tests/live/motion_test.tscn -- <模型.inx> <資料夾>/_packs pack=<包> [nophys]
python Tools/art/motion_sheet.py <資料夾>/_packs --max=16
```

每個參數 1.2 秒：0 → +1 → -1 → 0。包的內容定義在 `Tests/live/motion_test.gd` 的 `PACKS`。

## 看什麼

- 審查包：`_packs/sheet_pack_<包>.jpg`。
- 總表很小，關節看不清楚：從 `frames.json` 找出某個參數最大、最小的那幾格，裁出那一塊放大看。

### 注意重點

**L9 部件動作**
- 頭髮包（頭髮＋髮飾＋帽子）要打開擺動跑：看的是擺動本身。擺動太小看不出來（甩頭時髮尾只移動幾個像素）也算沒通過；太大時整片後髮甩出去也不行。
- 補畫層（`hidden`）只在被會動的零件蓋住時才補；畫到人物外面（武器、手上的東西後面）的，單獨測人物時會飄在空中；畫到頭髮該在的地方的，會蓋住後面的頭髮。
- 補畫層的空洞常剛好在零件正後面（大腿底下），靜止時完全看不到，只有這裡看得出來。零件後面的補畫層有沒有空洞。
- 武器、手上的東西轉起來時，黏在上面的別的東西（同色的裙子、背景碎片）會跟著飛。
- 長的武器（法杖、長槍）跟著手臂轉，末端會甩很遠：綁定時讓握點反向轉一部分（`inx_rig.UPRIGHT`）。
- 關節看不清楚時不要只看這張總表：頭髮、手上的東西常擋在關節前；只疊那幾段零件照轉軸轉來看（LessonsLearned 十一）。
- 身體包的腰彎轉到 ±1 時長裙裂開是已知問題（標準動作不用腰彎）。

## 修法選單

| 修法 | 什麼時候用 |
|---|---|
| `to_objects` | 零件或補畫層要修 |
| `rerig` | 重新綁定（改了綁定規則） |

## 常見問題和現在的處理

| 問題 | 處理 | 狀態 |
|---|---|---|
| 關節在總表上看不清 | 放大最大、最小的格；只疊零件轉 | 看圖方法 |
| 腰彎時長裙裂開 | 不用腰彎 | 已知未修 |
