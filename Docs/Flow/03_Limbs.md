# 3. 切四肢零件（L3）

回到 [主流程](README.md)。

## 做什麼、為什麼

拆層模型只給整隻手臂（`handwear-l/r`，連手套）和兩條腿一層（`legwear`）、鞋子一層（`footwear`）。這一步照關節切成會轉的零件：上臂、前臂、手；大腿、小腿、腳掌（連鞋），每段在關節多留一塊重疊；武器用 SAM2 切出來、算握點。零件移開後會露出的身體補畫在 `hidden`、`hidden-pelvis`。

## 輸入、輸出

- 輸入：`st/` 的圖層、`fig_joints.json`。
- 輸出：
  - `st/part_upperarm-l.png` 等 12 節。
  - `objects`（武器）、`objects-back`。
  - `hidden`、`hidden-pelvis`。
  - `parts.json` 的 `pivots`：肩、肘、腕、髖、膝、踝、腰、握點和武器尖端。
- 接著跑一次分包（`split_groups.py`），出四肢、武器、補畫層的總表。

## 指令

```
python Tools/art/rig_parts.py <角色> <造型> [--weapon x,y;... --not x,y;...]   要 ComfyUI（SAM2），約 1 分
python Tools/art/split_groups.py <角色> <造型>
```

手肘、手腕優先用 `fig_joints.json`（L1 確認過的）；不在手臂上或順序不對才沿手臂比例推估。握點取「手最大的那一塊碰到武器最多的地方」。

## 看什麼

- 審查包：`st/groups/parts_4.jpg`（四肢）、`parts_5.jpg`（武器）、`parts_3.jpg`（`hidden`）。

### 注意重點

**L3 切零件**
- 手臂被袖子切斷、垂布比手還低時，肘、腕的位置容易切錯（`rig_parts.cut_arm`）。
- 上臂不能有超過肩膀、伸到身體那一側的部分，不然轉肩膀時會掃過脖子（`rig_parts.cut_arm`）。
- 四肢零件不能省：上臂、前臂、手；大腿、小腿、腳掌連鞋（原則 7）。
- 武器：SAM2 會流進同色的深色裙襬；被裙子擋住的杖下半截要補到腳底；補畫的部分要連著武器，不連的碎塊轉動時會留在原地（`rig_parts.py`）。
- 握點：程式取「碰到武器最多的手」，會抓錯（LessonsLearned 四）。
- `hidden`（手臂底下補畫的身體）：貼著皮膚的地方 AI 會畫出手臂的殘影；手臂和身體之間的空隙不該被補成一條皮膚；頭髮後面常補成灰色糊塊（`rig_parts.py`、五）。
- 站在裙子開衩裡的腿，後面要補成裙子內側。
- 四肢每一節都要在物件迴圈裡去毛邊、關節收成半圓：全部交 `to_objects`（2026-10-03）。
- 鏡像、補灰色糊塊這類要挑候選的修法，用 `to_objects` 交給物件迴圈。

## 修法選單

| 修法 | 什麼時候用 |
|---|---|
| `weapon_points` 照描點切武器 | 武器流進裙子、沒切完整 |
| `specks` 清碎點 | 零件上的碎點 |
| `rerun` 重跑 | 關節改過後重切 |
| `to_objects` | 鏡像、補洞、去毛邊、收關節這類要挑候選的，交物件迴圈 |

## 常見問題和現在的處理

| 問題 | 處理 | 狀態 |
|---|---|---|
| 被頭髮、火球擋住的那隻手臂：上臂是束腹邊、前臂碎片 | 物件迴圈用另一隻鏡像 | 選單 |
| 長裙開衩裡的腿只剩細條 | 物件迴圈鏡像 | 選單 |
| 手上黏著手上拿的東西（火） | 物件迴圈清掉 | 手改 |
| 握武器的手夾著一截杖身 | 物件迴圈 AI 重畫成空握 | 選單＋手改 |
| 四肢邊緣毛邊、黏一條裙子邊 | 物件迴圈 `defringe` | 選單 |

## 已知問題

- 鏡像來的手臂沒有關節重疊、形狀也不一定像（芙蕾雅的左上臂是露肩荷葉袖），見 [05_Objects](05_Objects.md)。
- 武器拿掉後，原本被武器擋住的身體後面沒補（芙蕾雅左手臂後面，極限測試約 270 像素的洞）。
