# 6. 組裝檢查（L6）

回到 [主流程](README.md)。

## 做什麼、為什麼

物件都通過之後，照 `parts.json` 的前後順序一包一包疊起來看：臉 → ＋頭髮 → ＋衣服 → ＋四肢 → ＋武器 → ＋其他。看的是前後順序、包和包之間接不接得起來、有沒有露出補畫的猜測、整個人有沒有洞。出問題就點名物件回物件迴圈。

## 輸入、輸出

- 輸入：所有圖層、`parts.json`。
- 輸出：`st/groups/assemble_1.jpg`～`assemble_6.jpg`（左：疊到這一包；右：原立繪），`groups.json`（人物範圍裡沒蓋到的比例，`missing_share`），`_score/L6_packs.json`（臉、頭髮、衣服的角色相似度）。

## 指令

```
python Tools/art/split_groups.py <角色> <造型>                              手改後也重畫
python Tools/art/char_score.py flag-packs <角色> <造型> <輸出.json>          提醒（[22d](../Design/22d_Character_Score.md)）
```

## 看什麼

- 審查包：`assemble_1.jpg`～`assemble_6.jpg`、`_score_L6_packs.json`。
- 只做人物時，「沒蓋到的比例」會因為拿掉的武器、手上的東西變高（芙蕾雅 5% → 17%），那不是洞。

### 注意重點

**L6 組裝檢查**
- 前後一律照 `parts.json`：換了順序會露出補畫的猜測（蕾娜的腰帶就是這樣不見的）。
- 帽帶在瀏海前、帽簷在頭後（原則 7）；披風在髮尾後面、側髮在上衣前、手臂後（LessonsLearned 八）。
- 前髮蓋住了護目鏡、眼睛這類東西（`review_plate.py` 的「前髮與原圖不同」）。
- 組裝圖不再標跟原圖的差異（2026-10-02 起）；像不像原圖不是標準（原則 2）。
- 改前後順序用 manual（改 parts.json 的順序）。
- `_score` 的分數超過界線的那一包要仔細看（只是提醒，不是結論）。

## 修法選單

| 修法 | 什麼時候用 |
|---|---|
| `to_objects` | 點名物件回物件迴圈（會重開凍結的物件，後面全部重跑） |
| `manual` | 其他（目前這一步的修正幾乎都是手改） |

## 常見問題和現在的處理

芙蕾雅主設計兩輪都在這一步手改：

| 問題 | 做法 | 狀態 |
|---|---|---|
| 臉（`make_face` 做的）下緣是水平直線，下巴兩邊多出方角 | 沿下巴線 (345,270)-(360,294)-(392,313)-(425,290)-(445,265) 切掉以下 | 手改 |
| 長髮一整片，擺不起來 | `object_fix front_hair --split-hair --hair-ends 3`（側髮兩片、髮尾三片）；清瀏海下的碎渣、髮尾的白塊 | 手改 |
| 法杖原位的裙子有一條縫 | 下著在自己的輪廓裡（閉合 41 像素）、杖身後面補 | 手改 |
| 臀部、開衩被四肢擋住的地方有洞 | 補畫層在那裡用周圍顏色補 | 手改 |

## 已知問題

- 上表都該做成工具或前面步驟的一部分（[待做成工具](README.md#待做成工具的手改)）：下巴可以在 `--make-face` 時就切；頭髮拆片可以在頭髮重畫完固定接；裙子和臀部的洞可以在第 3、4a 步補。
- 補的裙子和臀部有點糊（被腿擋著，動作時偶爾看得到）。
