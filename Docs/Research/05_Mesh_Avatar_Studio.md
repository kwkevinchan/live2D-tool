# Mesh Avatar Studio：程式助手把一張圖做成會動的網格角色

整理日期：2026-10-04。回到 [研究總覽](README.md)。專案 2026-10-04 才建立（43 顆星、MIT 授權；範例角色另有條款）。

## 一句話

給程式助手（Claude Code 或 Codex）一張正面的頭肩圖，照說明一步步讀座標、寫綁定設定、切幾個必要的圖層、渲染固定姿勢自己檢查；人再用網頁編輯器拖控制點微調。動的是**原圖本身**（用網格變形），不是重畫或完整拆層。

## 怎麼做

**圖層很少，大部分是原圖**
- `base.png`：整張原圖，只把手、前臂、流蘇挖掉補平。
- 單獨切出來的只有：手和前臂、流蘇、每隻眼睛的三塊（眼白加虹膜、上睫毛、下睫毛）。
- 頭髮**不切圖層**，只做一張「頭髮遮罩」，讓擺動只作用在頭髮上。
- 被擋住的地方都很小，**不用 AI 補**：用一般補圖（Telea）；眼皮下的皮膚用「薄膜」解法，從周圍的膚色和陰影平順地延伸進洞裡，看不出邊。手指擋住的下巴輪廓，用兩邊看得到的點連一條平滑曲線補。

**變形**
- 每個網格點有幾個權重：屬於頭多少（頭的橢圓加一條漸變帶到鎖骨）、轉頭時跟著多少、屬於哪一束頭髮。
- 轉頭：照權重平移、旋轉，加一個轉頭的位移函式。註解說先試過「投影到球面」，但球的邊緣斜率無限大、會折，所以放棄。
- 頭髮：每束頭髮是一條四個點的折線（根到尾），照它擺動。

**參數和範圍**（跟 Live2D 標準參數一樣小）

| 參數 | 範圍 |
|---|---|
| 頭左右、上下、歪頭 | ±30 |
| 身體左右、歪 | ±10 |
| 手臂、手腕 | ±10 |
| 眼睛開合 | 0～1.25 |
| 另有 | 視線、眉毛、嘴（開、形）、臉紅、呼吸、手指點 |

**眨眼**
- 眼睛那一塊的每個像素分成：眼白虹膜、上睫毛、下睫毛、眼皮摺痕。不是「確定是皮膚的顏色」就算線，免得睫毛移動後留下淡淡的筆跡。
- 底圖在眼睛位置先補上平的眼皮皮膚，睫毛往下滑蓋過去。
- 線的邊緣用「跟皮膚混合前的顏色加透明度」拆出來，移走時不留痕跡。
- 選用：叫圖像生成畫閉眼、笑眼、半閉、各個母音的嘴（給遮罩）；**遮罩外的像素有任何改變就退件重畫**。

**給程式助手的規矩**（`docs/agent-guide.md`）
- 開始前跑「視力校正」：讀一張有編號標記的圖，回答座標並評分；不及格就停，告訴使用者結果大概要大量手修。
- 每個零件**先做放大的格線圖再讀座標**，不准從整張圖估。
- 每一步都有檢查：疊圖看（眼睛的範圍誤差約 2 像素內）、渲染固定姿勢看每一格（閉眼要只剩一條乾淨的睫毛線、沒有殘留的虹膜；轉 ±30 度和歪頭不能撕裂、切到下巴或耳朵）。
- 修三輪還不行就停下來回報。
- 「不可接受」清單：不放大就估座標；跳過檢查；**沒看圖就說成功**；眼睛範圍包到睫毛或皮膚；閉眼看得到虹膜。
- 建議的模型裡有 Claude Opus 5.5。

## 限制

- 只做頭肩、正面；強烈的四分之三側臉、手或東西擋臉、頭髮大量蓋住臉，品質都會變差。
- 帽子、眼鏡、拿在臉前的東西，只能跟著頭或身體整塊動。
- 動作都很小；沒有全身、沒有大動作。
- 程式助手做完還要人在編輯器裡微調。

## 對我們的意義

**它的品質來源：不重畫、少拆。** 動的是原圖的像素，所以畫質就是原圖的畫質，沒有 AI 重畫的不一致，也沒有「被擋住的部分要猜」。這是我們流程的反面：我們把整張拆成三四十層、每層補齊、再大量重畫，品質一路掉。它用「動作小到幾乎不露出被擋住的地方」**避開了延伸**。

**可以直接學的：**
1. **只拆必須單獨動的東西**（眼睛、手、垂飾），其他留在原圖裡用網格變形。頭髮不拆層，用遮罩加權重擺動。
2. **小洞用確定的方法補**（膚色薄膜延伸、平滑曲線接輪廓），不叫 AI 猜。
3. **眼睛的像素分類**：眼白虹膜、上睫毛、下睫毛、摺痕，加上眼皮下補平的皮膚；比我們現在的眨眼更乾淨。
4. **給程式助手的檢查規矩**：視力校正、放大格線讀座標、固定姿勢每格看、三輪停損、沒看圖不准說成功。跟我們的教訓幾乎一樣（[../LessonsLearned.md](../LessonsLearned.md)）。
5. **AI 畫的差分圖，遮罩外的像素有變就退件。**

**跟我們的方向怎麼接：** 它只做待機的小動作。大動作（技能）可以用「從原圖局部重畫手臂、其他像素不動」生成關鍵姿勢，兩者的原則一樣：**原圖的像素盡量不動**。
